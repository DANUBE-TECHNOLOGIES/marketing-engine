# MSE-25.193 — GEO grounded local context navigation V1

## Problem

`LocalContentContext` still generated fixed links to the agency root plus `/services`, `/destinations`, `/inspiration` and `/contact`, independently of the pages actually published for the mini-site.

That could expose navigation toward routes with no published page authority, despite the grounded-navigation contract already enforced in the global navigation and local-area block.

## Contract

- Related local-context links come only from `uniquePublishedNavigation(site)`.
- The current published page is excluded from the related links.
- URLs are generated by canonical `pageHref(site.slug, page)`.
- Labels reuse the exact published page title.
- No fixed agency subroute is generated.
- If no alternative published page exists, the related navigation block is omitted.
- Existing factual local context remains grounded in configured target cities and published page/service data.

## Scope

Public Mondescale mini-sites GEO only. No agent, Orchestra, Knowledge or remediation changes.
