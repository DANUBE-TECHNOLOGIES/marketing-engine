# ADR-0008 — Travel Core central

- Statut : Acceptée
- Date : 2026-08-02

## Contexte

La plateforme Mondescale comporte plusieurs moteurs appelés à évoluer indépendamment.

## Décision

Travel Core est la source unique des pays, régions, destinations, villes, aéroports, hôtels, circuits et offres de référence.

## Conséquences

Les contenus ne dupliquent plus les données métier.

## Critères de conformité

- La décision doit être respectée dans les nouveaux développements.
- Toute exception doit être documentée dans une nouvelle ADR.
