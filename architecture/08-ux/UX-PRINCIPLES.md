# UX Principles

1. Les écrans reflètent les tâches réelles des équipes.
2. Une action courante nécessite le moins d’étapes possible.
3. Les données automatiques affichent leur source et leur fraîcheur.
4. Les modifications importantes sont prévisualisables et réversibles.
5. Le SaaS reste utilisable par une personne non technique.
6. Les interfaces admin et publiques partagent les mêmes design tokens.
