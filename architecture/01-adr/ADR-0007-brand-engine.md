# ADR-0007 — Brand Engine central

- Statut : Acceptée
- Date : 2026-08-02

## Contexte

La plateforme Mondescale comporte plusieurs moteurs appelés à évoluer indépendamment.

## Décision

Le Brand Engine est l’unique source pour logos, couleurs, typographies, ton et signatures.

## Conséquences

Les mini-sites, newsletters, campagnes et documents restent cohérents.

## Critères de conformité

- La décision doit être respectée dans les nouveaux développements.
- Toute exception doit être documentée dans une nouvelle ADR.
