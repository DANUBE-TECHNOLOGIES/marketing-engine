# Sprint 1 — Architecture et fondations

## Objectif

Préparer la construction du Marketing Engine et des mini-sites autour du Local Engine existant.

## Livrables

- référentiel d’architecture ;
- cartographie des capacités ;
- modèle métier initial ;
- Travel Knowledge Graph V1 ;
- matrice de transformation ;
- stratégie de migration ;
- spécification Mini-site Engine V1.

## Hors périmètre

- migration immédiate des modules Google ;
- modification de l’ERP ;
- mise en production immédiate d’un mini-site ;
- interruption du Local Engine existant.

## Definition of Done

- documentation versionnée ;
- capacités existantes classifiées ;
- Domain Model V1 validé ;
- Knowledge Graph V1 validé ;
- périmètre du Sprint 2 défini.
