# Search Console indexation runbook

This runbook activates sitemap submission only after Local Engine has validated indexation readiness.

## Safety contract

- Search Console is disabled unless `SEARCH_CONSOLE_ENABLED=true`.
- No Google credential belongs in Git.
- The submitted sitemap URL is generated by Local Engine: `https://agences.mondescale.com/agence/{siteSlug}/sitemap.xml`.
- The Google identity must expose the target property with `permissionLevel=siteOwner`.
- `preflight` performs no Search Console write.
- Submission still requires an explicit approval journal entry before the `submit` action.

## 1. Install the Google authentication dependency

From `backend/`, run npm so that `package.json` and `package-lock.json` are updated together:

```bash
npm install google-auth-library@10.5.0 --save-exact
npm test
```

Do not edit `package-lock.json` manually.

## 2. Store the Google credential outside the repository

Example server layout:

```text
/run/secrets/mondescale/search-console.json
```

Recommended permissions:

```bash
sudo install -d -m 0700 /run/secrets/mondescale
sudo chmod 0600 /run/secrets/mondescale/search-console.json
```

The credential file must never be copied under the repository. The repository ignores `secrets/`, `backend/secrets/`, service-account JSON patterns and Search Console credential JSON patterns as an additional safeguard.

## 3. Configure the backend

```env
SEARCH_CONSOLE_ENABLED=true
GOOGLE_APPLICATION_CREDENTIALS=/run/secrets/mondescale/search-console.json
```

The default scope used by Local Engine is:

```text
https://www.googleapis.com/auth/webmasters
```

Restart the backend only after the credential path exists for the runtime user/container.

## 4. Verify provider health

```bash
curl -sS \
  -H 'x-tenant-slug: mondescale' \
  http://127.0.0.1:4000/search-console-submissions/health | jq
```

Expected conditions:

- `provider = google-search-console`
- `providerConfigured = true`
- `configurationState = ready`
- `explicitApprovalRequired = true`
- `autoSubmit = false`

## 5. Verify Search Console property access

```bash
curl -sS \
  -H 'x-tenant-slug: mondescale' \
  http://127.0.0.1:4000/search-console-submissions/properties | jq
```

The target property must be present and must have `permissionLevel: siteOwner`.

## 6. Run the read-only preflight for one agency

Example for Gien using the domain property:

```bash
cd backend
TENANT_SLUG=mondescale \
SITE_SLUG=gien \
SEARCH_CONSOLE_SITE_URL='sc-domain:agences.mondescale.com' \
BACKEND_ORIGIN='http://127.0.0.1:4000' \
npm run search-console:check
```

A successful result must report `ok: true`, the canonical agency sitemap URL and all checks as successful.

The preflight verifies:

1. the mini-site is published and `readyToSubmit`;
2. the sitemap URL matches the Local Engine canonical contract;
3. the public sitemap responds successfully;
4. the public body is a sitemap XML `urlset`;
5. the Google property is accessible;
6. the permission level is `siteOwner`.

## 7. Prepare the journal entry

Only after preflight succeeds:

```bash
curl -sS -X POST \
  -H 'Content-Type: application/json' \
  -H 'x-tenant-slug: mondescale' \
  http://127.0.0.1:4000/search-console-submissions/prepare \
  -d '{
    "siteSlug": "gien",
    "siteUrl": "sc-domain:agences.mondescale.com",
    "requestedBy": "operator"
  }' | jq
```

The response must be `awaiting_approval`. Keep the returned run id.

## 8. Explicit approval

```bash
curl -sS -X POST \
  -H 'Content-Type: application/json' \
  -H 'x-tenant-slug: mondescale' \
  http://127.0.0.1:4000/search-console-submissions/RUN_ID/approve \
  -d '{"approvedBy":"operator"}' | jq
```

## 9. Submit

Submission is the only step that writes to Google Search Console:

```bash
curl -sS -X POST \
  -H 'x-tenant-slug: mondescale' \
  http://127.0.0.1:4000/search-console-submissions/RUN_ID/submit | jq
```

The run/action/audit event persists the result. Never bypass `prepare` and `approve`.

## Rollback / emergency stop

Disable Search Console immediately and restart the backend:

```env
SEARCH_CONSOLE_ENABLED=false
```

The provider returns to the disabled implementation. Public mini-sites and sitemap rendering remain available; only Search Console submission capability is disabled.
