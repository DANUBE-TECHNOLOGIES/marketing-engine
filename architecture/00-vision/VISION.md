# Vision — Mondescale Marketing Engine

## Mission

Construire un système d’exploitation marketing spécialisé dans le tourisme, capable de :

- comprendre les connaissances métier ;
- produire des contenus cohérents ;
- adapter ces contenus à plusieurs canaux ;
- publier et planifier ;
- mesurer les performances ;
- détecter les opportunités ;
- améliorer les contenus en continu ;
- piloter la visibilité locale d’un réseau d’agences.

## Architecture fonctionnelle cible

Marketing Engine
├── Travel Knowledge Graph
├── Content Engine
├── Mini-site Engine
├── Publication Engine
├── Local SEO Engine
├── Analytics Engine
└── Automation Engine

## Position du Local Engine

Le Local Engine actuel constitue la première implémentation du futur Local SEO Engine.

Capacités existantes :

- Google Business Profile ;
- Google Posts ;
- contrôle des similarités ;
- planification des publications ;
- avis Google ;
- demandes d’avis ;
- citations locales ;
- rankings ;
- scores SEO ;
- actions réseau ;
- automatisations ;
- snapshots ;
- rapports ;
- supervision technique.

Ces capacités doivent être conservées, stabilisées et intégrées progressivement au Marketing Engine.
